# Fall 2026 Gradebook

A single-page tracker for Fall 2026 courses (SOCIOL 1197, GENED 1089, ITAL 10, STAT 100), built from the course syllabi.

- Enter scores as `92`, `18/20` or a letter (`A-`); category weights come from each syllabus.
- "What if" fields and the slider project your final grade; the target panel shows the average you need on remaining work for each letter.
- Overview and "All due dates" list upcoming deadlines across courses.

Open `index.html` in a browser. Data is saved in the browser's local storage (or to your account when opened as a Claude artifact).
